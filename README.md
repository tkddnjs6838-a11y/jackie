# WAKKUBALL SMASH — 왁꾸볼 뿌스기

**개발: jackie** · Unity 3D 액션 게임 개인 프로젝트

말랑한 왁스볼 몬스터를 공격하고, 무기와 증강을 활용해 다섯 스테이지의 보스에 도전하는 게임입니다.

## 게임 구성

- **전투:** 칼·도끼 근접 공격, 샷건·기관총·레이저총 사격, 대시 회피
- **성장:** 증강 선택과 시간제 강화 아이템
- **타격 표현:** 몬스터의 눌림·반동·균열·처치 시 파편 효과
- **스테이지:** 초원 → 협곡 → 왁스 호수 → 수정 고원 → 분화구
- **보스:** 내려찍기, 돌진, 연속 점프, 공중 수정 공격·연결 방어, 용암 투척·흐름

## 조작

| 입력 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 시점 조작 |
| 마우스 왼쪽 버튼 | 공격 / 사격 |
| Space | 대시 |
| 1–5 | 획득한 무기 교체 |
| R | 재장전 |
| Tab | 보유 증강 확인 |

## 프로젝트 실행

1. 이 저장소를 다운로드하거나 `git clone`합니다.
2. Unity Hub에서 프로젝트 폴더를 추가합니다.
3. **Unity 6000.3.19f1**으로 열고 패키지와 에셋 임포트가 끝날 때까지 기다립니다.
4. `Assets/Scenes/SampleScene.unity`를 열고 Play를 누릅니다.

메인 씬과 다섯 맵이 Build Settings에 등록되어 있습니다. 실행 파일은 소스 저장소와 별도로 배포합니다. Mac 빌드는 에디터 메뉴 `Tools > Build > Mac Game`에서 만들 수 있습니다.

## 제작 도구

- **Unity / C#:** 게임 로직, 전투, UI, 맵, 효과 구현
- **Blender:** 모델 조정과 리깅 작업
- **VARCO3D:** 캐릭터·몬스터·보스의 3D 모델 생성에 활용
